# Rock-Paper-Scissors Game 

A simple and interactive Rock Paper Scissors game built using **HTML**, **CSS**, and **JavaScript**. Players can compete against the computer, track scores in real-time, and enjoy a clean and responsive user interface.

## 🚀 Features

* Play Rock, Paper, Scissors against the computer
* Random computer move generation
* Real-time score tracking
* Interactive user interface
* Visual feedback for wins, losses, and draws
* Responsive and beginner-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 How to Play

1. Click on Rock, Paper, or Scissors.
2. The computer will randomly select its move.
3. The winner is determined based on the standard game rules:

   * Rock beats Scissors
   * Scissors beats Paper
   * Paper beats Rock
4. Scores are updated automatically after each round.

## 💻 Getting Started

1. Clone this repository.


2. Open the project folder.

3. Run `index.html` in your browser.
